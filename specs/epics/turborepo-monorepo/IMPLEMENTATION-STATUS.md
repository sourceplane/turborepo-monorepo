## Departures from the upstream template

Everything not listed here is the template as it is upstream at `d95ea89`.

| # | What | Why |
|---|---|---|
| 1 | `engines.node` `>=22` (was `>=24`); `packageManager` `pnpm@10.12.1` (was `pnpm@11.25.0`); the lockfile regenerated by pnpm 10 | The runners and the composition give Node 22 and pnpm 10; nothing in the template needs more (risk TR-B) |
| 2 | The root `package.json` and `turbo.json` carry the workspace's own scripts and tasks beside the template's (`typecheck`, `test`, `wire:fixture`, `deploy`); `pnpm-workspace.yaml` adds `tests/*` and `tooling/*` and the build-script allow-list | One workspace for the template and the baseline's test and tooling packages |
| 3 | Each app's `next.config.js`: `output: "standalone"`, `outputFileTracingRoot` and `turbopack.root` at the workspace root, `images.unoptimized`, and the live preview's dev origins | OpenNext builds from the standalone output; Workers has no image optimiser (every image is an SVG) |
| 4 | Each app's `build` is `next build`, then `opennextjs-cloudflare build --skipBuild` and `populateCache local`; `preview` runs wrangler dev over it; `@opennextjs/cloudflare` 1.20.11 and `wrangler` 4.151.0 added | The Workers build |
| 5 | Each app: `open-next.config.ts` (the static-assets incremental cache), `wrangler.jsonc`, an app `turbo.json` naming `.open-next/**` as output, `component.yaml` | The Workers build and its deploy contract |
| 6 | `packages/ui/src/site.ts` (`SITE_NAME`, exported as `@repo/ui/site`); both layouts' `metadata.title` reads it (was the literal "Create Next App", still its default) | One rename seam, shared as the apps share everything else |
| 7 | `@repo/eslint-config/next.js` ignores `.open-next/**` and `.wrangler/**` | ESLint otherwise lints the Worker bundle OpenNext writes into each app (risk TR-C) |
| 8 | `@repo/ui`'s `Card` link drops a stray `"` from the end of its `href` (`…utm_campaign=create-turbo"`) | An upstream typo that put the quote into every Card's URL; neither app renders a Card |
| 9 | `next-env.d.ts` is not tracked | Next writes it on every build and `next typegen`; the workspace ignores it |
| 10 | The upstream licence as `LICENSE.md` in each directory the code came from | The template's credit travels with its code |
| 11 | The template's root `AGENTS.md` (Turborepo's agent block) is part of the product's `AGENTS.md` | `turbo` keeps that block in the file when it detects a coding agent |
| 12 | `tests/ui` (vitest), and `tooling/eslint` carrying its own TypeScript 5 | The template ships no tests; typescript-eslint refuses TypeScript 7 (risk TR-E) |
